# Anamnesis vault

This folder is a second brain. The rules are in the constitution, which is imported here so it is always in context:

@constitution.md

## Working here

- The `pi brain` CLI does every mechanical step (capture, episodes, log, lint, search, band). Use it rather than hand-editing `raw/`, `episodic/` or `log.md`; it validates input and keeps the files consistent.
- Four skills run the loops: `anamnesis-capture`, `anamnesis-ingest`, `anamnesis-query`, `anamnesis-lint`.
- Read `index.md` before answering questions about what is in the vault.
- When an answer you give is worth keeping, offer to file it as a note.
